「メタらない？」プライバシーポリシー

制定日：2026年9月30日

本プライバシーポリシーは、メタルバンド探索アプリ「メタらない？」 （以下「本アプリ」）におけるユーザー情報および関連データの取扱いを定めるものです。 本アプリは、ユーザーの音楽嗜好をもとにメタルバンドの探索・推薦・記録を支援します。

1. 取得・利用する情報

情報の種類主な内容利用目的
アカウント情報 Firebase UID、メールアドレス、表示名、認証プロバイダ、メール認証状態等 ログイン、アカウント管理、クラウド同期
認証情報 メール認証、Google等の外部認証に必要なトークンや認証結果 本人認証。メールアドレス/パスワード認証のパスワードはFirebase Authenticationが処理し、本アプリが平文で保存することはありません

2. 端末内保存とクラウド同期

Android版ではログアウトすると端末の図鑑・評価・DNA・Spotify/Last.fm連携情報を削除します。 クラウドに保存済みの記録と、ユーザーが書き出したJSONファイルは削除しません。 未同期の記録はログアウト前に「同期・バックアップ」で保存してください。 自動保存は初期状態では無効で、利用者が有効にすると変更後にまとめてクラウドに保存します。

本アプリのMetal DNA、評価履歴、検索履歴、Local Metal DB、設定情報等は主としてユーザー端末内に保存されます。 アカウントにログインしクラウド同期を利用する場合、これらの一部をFirebase Storageへバックアップし、 Firebase Firestoreにバックアップ形式・バージョン・更新日時等の管理情報を保存する場合があります。

Android版のクラウド同期用バックアップには、Spotifyのアクセストークン、リフレッシュトークン、 トークン有効期限を含めない設計としています。 ただし、端末のOSバックアップ機能が有効な場合、OSまたはプラットフォーム提供者の仕様に基づき アプリデータがバックアップされる場合があります。

3. 第三者サービスへの送信・共有

本アプリは、機能提供のため以下の外部サービスへ必要な情報を送信する場合があります。 当該サービスに送信された情報は、各サービス提供者のプライバシーポリシーに従って取り扱われます。

  • Google / Firebase：Authentication、Storage、Firestore、Googleログイン
  • Spotify：OAuth認証、Top Artists、Recently Played、アーティスト・楽曲・アルバム検索
  • Last.fm：アーティスト検索、タグ、類似アーティスト、統計情報、およびユーザーが任意連携した場合の公開Top Artists / Recent Tracks
  • MusicBrainz：アーティスト情報・同名アーティスト識別
  • Apple iTunes Search API：Spotify本人照合を補助する公開カタログ情報の確認
  • Meta / Apple / X：ユーザーが該当ログイン方法を選択し、かつ当該機能が有効な場合の認証
  • YouTube：ユーザーがYouTubeボタンを押した場合、外部のYouTube画面または検索画面を開きます

本アプリは、ユーザーデータを第三者へ販売しません。また、広告配信を目的としてユーザーデータを販売・提供することはありません。

4. Spotify / Last.fm連携について

Spotify連携は任意です。ユーザーがSpotify連携を開始した場合、 本アプリは user-top-read および user-read-recently-played 等の権限を用いて、Top ArtistsやRecently Playedを取得し、Metal DNA推定に利用します。

Last.fmプロフィール連携も任意です。ユーザーがLast.fmユーザー名を入力した場合、 本アプリはLast.fm上で公開されているTop ArtistsおよびRecent Tracksを取得し、 Metal DNA推定とアーティスト発掘Seedの生成に利用します。本アプリはこの機能のために Last.fmのパスワードまたはLast.fmユーザーsession keyを保存しません。

Spotify / Last.fmのいずれも連携しなくても、ジャンル選択や通常の発掘機能から本アプリを利用できます。

5. データの安全管理

本アプリは、外部サービスとの通信に原則としてHTTPSを使用し、 認証・クラウド保存はFirebase等の提供する仕組みを利用します。 また、クラウド同期用バックアップから再利用可能なSpotifyログイントークンを除外するなど、 機能上不要な認証情報をクラウドへ保存しないよう配慮しています。

ただし、インターネット通信や端末保存に絶対的な安全性を保証するものではありません。

6. データの保持期間

端末内データは、ユーザーがアプリデータを削除する、アプリをアンインストールする、 または当該データをアプリの機能により削除するまで保持される場合があります。 クラウド同期データおよびアカウント情報は、サービス提供に必要な期間、またはユーザーがアカウント削除を行うまで保持されます。

7. アカウントおよびデータの削除

本アプリ内のアカウント設定からアカウント削除を実行した場合、 Firebase Storage上のユーザーバックアップ、Firestore上のユーザー管理情報、 およびFirebase Authentication上のアカウントの削除を行います。

アカウント削除後も、ユーザー端末内のローカルJSON、Local Metal DB、評価・検索履歴等は 端末上に残る場合があります。これらの端末内データも削除したい場合は、 Androidの「アプリ情報」から本アプリのストレージ/データを削除するか、本アプリをアンインストールしてください。

外部サービス側に保持されている情報の削除については、各外部サービスのアカウント設定・プライバシーポリシーをご確認ください。
