# Google Play公開手順

公式: https://support.google.com/googleplay/android-developer/answer/6112435?hl=ja

1. Play Console developer accountを作成する。
2. 配布契約へ同意する。
3. 1回限りの登録料25 USDを支払う。
4. 個人用/組織用accountを選択し本人確認を完了する。
5. Play Consoleでアプリを作成する。
6. Privacy / Data safety / Store listingを入力する。
7. 固定署名でrelease AABを作成してテストtrackへUploadする。
8. 個人developer accountに適用されるテスト要件が表示された場合は、Consoleの現行要件に従う。

公開直前には必ずPlay Console内の最新要件を再確認する。
